# 國中全科刷題網

平板／手機打開就能刷題，不用登入。分類：**科目 → 冊次 → 單元**。

- 科目：國文、英語、數學、自然、社會、科技、藝術、健體、綜合、閩語
- 冊次：第一～六冊、第六冊（超進度）、基測（分年度）、會考（分年度），可複選
- 每回 10／20／30 題，各單元平均出題、優先出沒做過的題目
- 答錯 → 從同單元找**同一個觀念**的類似題，連續答對 2 題才過關
- 答錯的題目自動進「錯題本」，之後答對就移出
- 做題紀錄存在該台裝置的瀏覽器（localStorage）

## 放上 GitHub Pages

1. 在 GitHub 建一個新 repository（例如 `quiz`），設為 Public。
2. 把這個資料夾裡的所有檔案上傳（`Add file → Upload files`，整個資料夾拖進去）。
3. `Settings → Pages → Build and deployment`：Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 約 1 分鐘後網址會出現在同一頁：`https://<你的帳號>.github.io/quiz/`
5. 在平板用 Safari／Chrome 打開 → 分享 →「加入主畫面」，就像 App 一樣。

## 資料夾結構

```
index.html  app.js  style.css  icon.svg
data/
  catalog.json                 ← 科目、冊次、單元名稱（網頁的選單）
  <科目id>/<冊次id>/<單元id>.json  ← 一個單元一個檔
  <科目id>/<冊次id>/img/…       ← 題目附圖
tools/build_catalog.py         ← 更新題數＋檢查格式
```

科目 id：`chinese` 國文、`english` 英語、`math` 數學、`nature` 自然、`social` 社會、`tech` 科技、`arts` 藝術、`health` 健體、`integ` 綜合、`minnan` 閩語
冊次 id：`1`～`6`、`6x` 第六冊（超進度）、`bc` 基測、`cap` 會考

## 題目格式（每個單元檔是一個陣列）

```json
[
  {
    "id": "1503000001",
    "s": "為了能延長食品保存期限，一般都在食品包裝中填充下列何種氣體？",
    "o": ["氮氣", "二氧化碳", "氦氣", "臭氧"],
    "a": 0,
    "e": "氮氣性質安定，可保持食物新鮮。",
    "k": ["空氣中主要氣體成分"],
    "d": "中"
  }
]
```

| 欄位 | 說明 |
|---|---|
| `id` | 題號，同單元內不可重複 |
| `s` | 題目文字 |
| `o` | 選項（2～6 個）；整題都在圖裡時可省略 |
| `a` | 正確答案，從 0 算起（0=A、1=B、2=C、3=D） |
| `e` | 詳解（選填） |
| `k` | 觀念標籤，第一個用來找「類似題」（選填，建議填） |
| `d` | 難易度：易／中／難（選填） |
| `img` | 附圖路徑，相對於冊次資料夾，例如 `img/1503000008.jpg`（選填） |
| `n` | 沒有 `o` 時的選項數，預設 4 |

在 `catalog.json` 對應冊次的 `units` 加上單元（社會、自然可加 `group` 分組，例如 `"group": "地理"`）：

```json
{ "id": "2-3", "name": "2-3 空氣的組成", "group": "理化" }
```

新增或修改題庫後，執行一次：

```
python3 tools/build_catalog.py
```

它會更新每個單元的題數，並檢查答案超出範圍、題號重複、找不到圖片等問題。
